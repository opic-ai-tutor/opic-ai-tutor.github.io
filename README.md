# OPIc AI 튜터

OPIc 방식 말하기 연습 웹앱이에요. 난이도와 설문을 넣으면 AI가 12~15문제(난이도 1~2는 12문제)를 만들고, 질문을 소리로 들려줘요. 내가 말한 답은 글로 옮겨지고, 세트가 끝나면 피드백을 받아요.

## 쓸 수 있는 AI
설정에서 하나를 고르고 그 회사의 API 키를 넣어요. 키는 제공사별로 따로 저장돼요.

| AI | 키 받는 곳 | 비용 |
|---|---|---|
| Gemini (Google) | [Google AI Studio](https://aistudio.google.com/apikey) | 무료 키 가능. 같은 키에 결제를 연결하면 유료 등급 |
| GPT (OpenAI) | [OpenAI Platform](https://platform.openai.com/api-keys) | 크레딧 충전 필요 (ChatGPT Plus와 별개) |
| Claude (Anthropic) | [Claude Console](https://console.anthropic.com/settings/keys) | 크레딧 충전 필요 (Claude Pro/Max와 별개) |

- 고른 모델이 붐비거나(503) 없으면(404), 같은 회사의 다른 모델로 최대 3개까지 자동으로 바꿔 가며 다시 시도해요. Gemini 무료 한도(429)에 걸렸을 때도 다른 모델로 시도해요.
- 유료 키는 꼭 사용 한도(월 예산)를 걸어 두세요.

## 파일
- `index.html`: 웹앱. 이 파일 하나만 있으면 돼요.
- `말하기세트 프롬프트.md`: 앱 없이 Gemini 앱, ChatGPT, Claude에 붙여 넣어 쓰는 버전.

## 시작하기 (5분)
1. 위 표에서 쓸 AI를 골라 API 키를 받아요. 처음이라면 Gemini 무료 키가 가장 쉬워요.
2. `index.html`을 **Chrome이나 Edge**로 열어요. (Firefox는 음성 인식이 안 돼요.)
3. 오른쪽 위 **설정**에서 AI를 고르고 키를 넣은 뒤, **키 확인 · 모델 목록**을 눌러 확인하고 저장해요.
4. 난이도와 구성 → 설문 → 문제 만들기 순서로 진행해요.

## 연습 화면
- 질문은 소리로 먼저 나오고, 글자는 "질문 글자 보기"를 눌러야 보여요. (설정에서 처음부터 보이게 바꿀 수 있어요.)
- **답변 시작**을 누르고 말하면 글로 옮겨지고, 타이머와 단어 수가 표시돼요. 목표는 1분~1분 50초(약 120~220단어)예요.
- 전사본은 직접 고치거나, 다른 곳에서 받아 적은 글을 붙여 넣어도 돼요.
- 내 녹음은 다시 들을 수 있어요. 새로고침하면 사라져요.
- 세트 마지막 문항에서 **이 세트 피드백 받기**를 누르면 돼요.

## 피드백
- 최대 7개 내외, 문법·표현·어휘·업무 문장으로 나눠요. 내 문장 → 고친 문장 → 이유.
- AI가 전사본에 없는 문장을 인용하면 "전사본에서 그대로 찾지 못한 인용"이라고 표시돼요.
- 질문 적합성, 시제, 세트 안 연결, 분량을 한 줄씩 점검해요.
- 발음과 억양은 평가하지 않아요. 녹음을 직접 들어 보세요.

## 명령 버튼
- **새세트**: 같은 설문과 난이도로 새 세트 (이전에 낸 질문과 겹치지 않게)
- **난이도변경**: 난이도를 다시 골라 바로 출제
- **설문수정**: 설문을 고쳐 다시 출제

## 내보내기
- 문제지 .md, 전체 기록 .md(답변, 피드백, 예상 등급 포함)

## 알아 둘 것
- **키 보안**: 키는 이 브라우저에만 저장돼요. 키를 넣은 화면을 공유하지 마세요. AI Studio 결제 계정을 연결했다면 사용 한도를 걸어 두세요.
- **보내는 데이터**: 설문과 답변 전사본은 고른 AI 회사로 보내져요. Gemini 무료 등급으로 보낸 내용은 Google 서비스 개선에 쓰일 수 있어요. 회사 기밀(고객사명, IP, 설정 원본)은 넣지 마세요.
- **Gemini 상태 확인**: 붐비는지 궁금하면 [aistudio.google.com/status](https://aistudio.google.com/status)를 보세요.
- **음성 인식**: Chrome의 음성 인식은 소리를 Google 서버로 보내 처리해요. 인터넷이 필요해요.
- **기록**: 설문, 문제, 답변, 피드백은 이 브라우저에만 저장돼요. 새세트를 만들면 이전 세트가 지워지니 먼저 "전체 기록 .md"를 받아 두세요.
- **무료 한도 초과(429 오류)**: 앱이 다른 Gemini 모델로 먼저 시도해요. 그래도 안 되면 1분쯤 기다리거나, 하루 한도라면 내일 다시 해요.

## 키 보안 (꼭 읽어 주세요)

앱 안에서 하는 보호만으로는 키를 100% 지킬 수 없어요. 내 컴퓨터에 악성 프로그램이나 악성 브라우저 확장이 있거나, 누군가 이 앱을 베낀 가짜 사이트에 키를 넣으면 막을 방법이 없어요. 그래서 **키가 새더라도 피해가 작게** 아래 설정을 함께 해 두세요.

### Gemini 키 제한 걸기
1. [Google Cloud 콘솔 → 사용자 인증 정보](https://console.cloud.google.com/apis/credentials)에서 AI Studio 키가 들어 있는 프로젝트를 골라요.
2. 키를 눌러 **애플리케이션 제한사항 → 웹사이트**를 고르고 `https://opic-ai-tutor.github.io/*`를 넣어요. 이제 다른 사이트에서는 이 키가 동작하지 않아요. (이렇게 하면 파일로 직접 연 앱에서도 동작하지 않아요. 로컬에서 쓸 키는 따로 만드세요.)
3. **API 제한사항 → 키 제한**에서 `Generative Language API`만 고르고 저장해요.
4. 결제를 연결했다면 **예산 및 알림**에서 월 예산을 걸어요.

### OpenAI 키
- 이 앱 전용 **프로젝트**를 만들고 그 안에서 키를 만들어요.
- 키 권한을 **Restricted**로 하고 모델 호출에 필요한 권한만 켜요.
- 프로젝트 **월 사용 한도(Budget)**를 작게 걸어요.

### Claude 키
- [Claude Console](https://console.anthropic.com)에서 이 앱 전용 **워크스페이스**를 만들고 그 안에서 키를 만들어요.
- 워크스페이스에 **월 사용 한도(Spend limit)**를 걸어요.

### 습관
- 키가 샜다고 의심되면 바로 키를 삭제하고 새로 만들어요. 몇 달에 한 번은 바꿔 주는 게 좋아요.
- 이 앱과 AI는 키를 채팅이나 다른 사이트에 입력하라고 절대 요청하지 않아요.
- `https://opic-ai-tutor.github.io/` 말고 다른 주소에서는 키를 넣지 마세요.
- 화면 공유나 녹화 중에는 설정 창을 열지 마세요.

## 잘 안 될 때
- 마이크가 안 됨: 주소창 왼쪽 아이콘에서 마이크를 허용해요. 파일로 열었을 때 매번 허용을 물으면, 이 폴더에서 로컬 서버를 띄워 `http://localhost:8000`으로 열어요. (Node.js가 깔려 있으면 됩니다.)
  ```bash
  npx --yes http-server -p 8000
  ```
- 모델 오류(404): 앱이 자동으로 다른 모델을 찾아 저장해요. 직접 고르려면 설정에서 "키 확인 · 모델 목록"을 누르고 모델 칸을 비운 뒤 목록에서 골라요.
- 목소리가 어색함: 설정에서 다른 영어 목소리를 골라요. Edge의 "Natural" 목소리가 가장 자연스러워요.
